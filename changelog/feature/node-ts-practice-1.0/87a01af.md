## Summary
- `.claude/hooks/log-event.mjs` previously logged every hook event under its
  bare `[EventName]` tag, making it impossible to tell from the log alone
  whether an event was fired by the app's own internal helper agents (e.g.
  session-title generation) or by a real, user-dispatched subagent — both
  carry an `agent_id`, but only user-dispatched subagents also carry a
  non-empty `agent_type`.
- Added an `isInternalAgentEvent(input)` check (`agent_id` present,
  `agent_type` empty/falsy) and used it to tag the bracketed event name as
  `[<EventName>:internal]` instead of `[<EventName>]` whenever it fires,
  covering any of the 33 hook events an internal agent can trigger, not just
  `SubagentStart`/`SubagentStop`.
- This lets internal-agent noise be grepped in or out of `events/*.log`
  separately from genuine subagent activity, without changing the log
  format, level rules, or any other event's output.
- Only this one commit is new in this push; the prior 21 commits listed
  above already have their own changelog entries.
