e7f706f Add message-api-learning: Claude Messages API exploration project

## Summary
- Adds a new sibling learning project, `message-api-learning/`, dedicated to the raw Claude Messages API (`@anthropic-ai/sdk`) in TypeScript — a single request/response call, with no agent loop or built-in tools, as distinct from the existing `agent-sdk-learning/` project.
- Structures the project like `node-learning/` and `agent-sdk-learning/`: one numbered topic folder per concept under `src/`, each with a runnable `index.ts` demo and an `index.test.ts` for its pure logic.
- Ships the first topic, `01-core-message-api`, covering a single `client.messages.create()` call (one user message in, one assistant message out), with response-parsing logic factored into `responseParsing.ts` so it can be unit-tested without making a live, billed API call.
- Establishes project conventions in `CLAUDE.md`: auth via a real `ANTHROPIC_API_KEY` (no OAuth/subscription path, unlike the Agent SDK), tests never call the live API, and `npm run start:<topic>` is the only way to trigger a real billed request.
- Includes standard project scaffolding: `package.json`/`package-lock.json`, `tsconfig.json`, `jest.config.ts`, `.env.example`, `.gitignore`, a checked-in `.claude/settings.json` permissions allowlist, and a `README.md` documenting setup and the topic list.
