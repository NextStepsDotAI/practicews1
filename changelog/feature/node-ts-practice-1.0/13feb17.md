## Summary
- Fixed `reviews/` (the `pr-reviewer` subagent's output directory) being documented in `CLAUDE.md` as committed to git, which contradicted `pr-reviewer.md`'s own instruction not to commit it — and nothing had actually been committing it. It's now gitignored like `logs/`, since a review runs *after* push, in the background, and can take minutes, so it can't ride along with the push it reviews; `pr-merge` only ever needs to read it locally.
- Fixed `.githooks/pre-push`'s branch-name extraction, which only stripped a leading `refs/heads/` and would fall through with the ref unchanged for anything else (e.g. a tag push under `refs/tags/`), causing it to be mistaken for a non-`main` branch and wrongly required to carry a `changelog/` entry. It now matches `refs/heads/*` explicitly and skips everything else.
- Both fixes came out of `pr-reviewer`'s first real review run against this branch's own prior work, closing the loop on the review/merge tooling added earlier in this push.
- This push also carries the branch's full accumulated work: the `node-learning/` TypeScript practice lab (16 topics, source + Jest tests), the `git-branch-pr` skill, the repo-wide skill-logging convention, the `changelog-writer` agent, the `.githooks/pre-push` hook, and the `pr-reviewer` subagent plus `pr-merge` skill.
