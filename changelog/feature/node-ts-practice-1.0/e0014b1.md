## Summary
- Stood up `node-learning/`, a Node.js + TypeScript learning lab with 17
  self-contained topics (modules, fs, events, streams, async, HTTP,
  Express, env/config, error handling, Jest, child processes, cluster/
  worker threads, buffers, crypto, timers/event loop, npm packages, and
  glob-and-grep), each with its own implementation and Jest test file, plus
  supporting `package.json`, `tsconfig.json`, `jest.config.ts`, and a
  `node-tutor` skill/`new-topic` command for scaffolding future topics.
- Built out a repo-wide workflow for shipping changes safely: the
  `git-branch-pr` skill (branch/push/PR creation) and `pr-merge` skill
  (merge gated on CI + review), backed by a `pr-reviewer` subagent that
  writes gitignored reviews to `reviews/<branch>/<short-sha>.md`, and a
  `changelog-writer` subagent that writes committed entries to
  `changelog/<branch>/<short-sha>.md` for every push — this file is one of
  those entries.
- Added a `pre-push` git hook (`.githooks/pre-push`, activated via
  `git config core.hooksPath .githooks`) that hard-blocks pushing any
  non-main branch whose new commits don't touch `changelog/`, so a
  changelog entry can never be silently left behind a push; documented the
  one-time setup in `CLAUDE.md`.
- Fixed real issues found by running the workflow end-to-end: reordered
  `git-branch-pr` so `changelog-writer` runs before the push instead of
  after (so the entry rides along in the same push), and fixed two issues
  `pr-reviewer` caught on its own first real run.
- Established a repo-wide convention that every skill logs its runs to the
  gitignored `logs/<skill-name>/<uuid>.md`, and added a `UserPromptSubmit`
  hook (`.claude/hooks/log-prompt.mjs`) that logs each prompt to
  `prompt/<session_id>.md` for local audit purposes.
