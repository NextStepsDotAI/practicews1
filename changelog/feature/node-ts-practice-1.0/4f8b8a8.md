## Summary
- Added a `pr-reviewer` subagent (`.claude/agents/pr-reviewer.md`) that reviews a branch's diff against its base for correctness bugs, security issues, and clear-cut reuse/simplification misses, classifies findings as blocking or advisory, and writes the verdict to `reviews/<branch>/<short-sha>.md`.
- Added a `pr-merge` skill (`.claude/skills/pr-merge/SKILL.md`) that gates merging a PR on CI/mergeable status and a current (non-stale) `pr-reviewer` review with no unresolved blocking findings, confirms the merge strategy (default squash) with the user, merges via `gh pr merge`, and cleans up the branch both remotely and locally — so review is enforced before a merge lands, not just checked after the fact.
- Updated `.claude/skills/git-branch-pr/SKILL.md` to dispatch `pr-reviewer` after opening a PR, wiring the new subagent into the existing branch/PR workflow.
