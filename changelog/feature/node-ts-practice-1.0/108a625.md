## Summary
- Stood up `node-learning/`, a self-contained Node.js + TypeScript practice lab (16 numbered topics from modules and fs through cluster/worker threads, buffers, crypto, timers, and npm packages), each with an implementation file and a Jest test, plus its own `CLAUDE.md`, README, and tooling config (`tsconfig.json`, `jest.config.ts`, `package.json`/`package-lock.json`).
- Added a `node-tutor` skill (`node-learning/.claude/skills/node-tutor/SKILL.md`) and a `/new-topic` command to scaffold and teach new topics in the lab, and a `git-branch-pr` skill (later hardened from a first real run) to standardize branching/committing/PR creation.
- Introduced a repo-wide convention that every skill logs its runs to a gitignored `logs/` directory, and a parallel convention (`changelog-writer` agent) that every push gets a changelog entry under `changelog/<branch>/<short-sha>.md` — this file is itself an example.
- Fixed a workflow-ordering bug where the changelog-writer was dispatched after the push instead of before, and closed the gap for good by adding a `.githooks/pre-push` hook that rejects any non-main push whose new commits don't touch `changelog/`, with `CLAUDE.md` and the `git-branch-pr` skill updated to document the required one-time `git config core.hooksPath .githooks` setup.
